# Excel VBA Process Automation Tool

## Overview
This Excel VBA tool automates a previously manual process using macros, user forms, and data validation.

## Problem
Manual certificate creation was time-consuming, error-prone, and required repetitive steps.

## Solution
I developed a VBA-based system that:
- Generates certificates automatically
- Validates user inputs
- Reduces manual errors
- Speeds up the process significantly

## Key Features
- VBA Macros
- UserForms
- Dynamic Data Validation
- Error Handling
- Excel-based Automation

## Technologies Used
- Microsoft Excel
- VBA (Visual Basic for Applications)
